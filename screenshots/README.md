## Capture guidelines (for future additions)

- Use the **dark theme** (the production default — no theme-toggle needed).
- Hide your browser chrome — Cmd+Shift+F in Safari, full-screen in Chrome, etc.
- Recommended viewport: **1440×900**.
- **JPG** for hero images at ~85% quality; **PNG** only when crisp typography matters more than file size.
- Do not include personally identifiable browser tabs in the screenshot frame.
